# 变更日志

## 0.1.0 · 2026-11-10

- 初始化 SvelteKit、Svelte 5、TypeScript 和 pnpm 工程。

- 提供站点搜索、分类、响应式首页和系统浅深主题。

## 2026-11-10 · 国际化基础

- 接入 Paraglide JS 3，中英文翻译资源覆盖现有页面与无障碍文案，新增语言切换入口。

- 增加资源一致性检查、生成流程和国际化开发规范，以及语言切换、回退和并发 SSR 回归测试。
