# Arcticons

百度贴吧、爱奇艺和网易邮箱的试用 SVG 图标来自 [Arcticons](https://github.com/Arcticons-Team/Arcticons)，通过 Iconify 的开源图标数据导出。

Arcticons 图标采用 CC BY-SA 4.0 许可。项目源代码与许可文本见 [Arcticons LICENSE](https://github.com/Arcticons-Team/Arcticons/blob/main/LICENSE)。

项目对 SVG 的 `currentColor` 和线宽做了本地化处理，以适配导航卡片；品牌色不改变原始几何图形。
